# ESP32-Based Smart Autonomous Waste Collection Robot

An autonomous robot that detects obstacles and moves on its own to collect waste, built using an ESP32 and Embedded C/C++.

## Features
- Autonomous movement with obstacle detection
- Navigation logic for avoiding obstacles
- Motor control through a motor driver

## Hardware Used
- ESP32
- Sensors (add the exact sensor names you used)
- Motor driver (add the model)
- Motors and chassis
- Power supply

## Software
- Embedded C/C++
- Arduino IDE

## How It Works
1. The sensors read distance and detect obstacles.
2. The ESP32 processes the readings.
3. The motor driver moves the robot based on the navigation logic.

## How to Run
1. Open the code in Arduino IDE.
2. Select the ESP32 board and the correct port.
3. Upload the code and power the robot.
